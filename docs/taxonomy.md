# MalakandBazaar — Category Taxonomy (seed data)

Two levels: **Category → Subcategory**. No per-category custom attributes —
sellers describe specifics in the free-text description. Subcategories therefore
carry the filtering weight, so they are deliberately granular.

Each row seeds as: `slug`, `name_en`, `name_ur`, `icon` (Material Symbols), `sort`.
Urdu names given for top-level here; subcategory Urdu filled in at seed time.

## Notes
- Cross-listed items (Tractors, Generators, Water Pumps, Bicycles) appear in more
  than one branch on purpose — buyers approach them from different mental models.
  Slugs must stay unique; duplicate concepts get branch-prefixed slugs
  (`vehicles-tractors` vs `agriculture-tractors-implements`).
- "Other X" tail subcategory in every branch catches what the list misses and
  gives admin a signal for which subcategory to create next.
- Counts: 26 categories, ~430 subcategories.
